Telegram Group Invitation Tool - Quick Guide

1. Install Python 3.10 or newer.
2. Run: pip install -r requirements.txt
3. Obtain TELEGRAM_API_ID and TELEGRAM_API_HASH from https://my.telegram.org.
4. Set both values as environment variables in the terminal.
5. Run: python manager.py
6. Choose "Add/login account" and complete Telegram's login verification.
7. Run: python add.py
8. Select an account and enter a group/channel where that account can create invite links.
9. Share the generated invitation link only with people who want to join.

Security:
- Keep sessions/, accounts.json, API credentials, login codes, and 2FA passwords private.
- The old vars.txt pickle storage is not used by this version. Add accounts again through manager.py.
- This version does not scrape members, automatically add users, or send unsolicited bulk messages.
